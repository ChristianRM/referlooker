3. Detailed Workflow

Step 1: Loading and Generation of X-Ray Queries

The script reads each .txt file in the vacancies/ folder and utilizes the LLM to extract key requirements (title, experience, technologies). It builds targeted Google search queries:

site:linkedin.com/in/ "open to work" "Senior Backend" ("Python" OR "FastAPI")
Step 2: Candidate Search and Filtering

To avoid IP bans and CAPTCHAs, searches are executed via Google Custom Search API (or SerpAPI) instead of scrapers. Only unique personal LinkedIn profile URLs (/in/) are kept.

Step 3: Profile Scraping

Using Playwright in headless mode with reusable session cookies, the script parses public profile layouts and retrieves: Headline, About, Recent Experience, and Skills sections.

Step 4: Local AI Candidate Match Screening (RTX 5070)

The extracted profile text and job description are evaluated by the local Ollama model (e.g. llama3.1:8b). It generates a matching score (0-100), validates OpenToWork, and summarizes key strengths and gaps.

Step 5: Reports Consolidation

Candidates scoring above 85% are stored in output/desirable_candidates.xlsx and desirable_candidates.txt, sorted by vacancy and score descending.
